## When to Use
用户明确要求生成或编辑位图时，与实际 imagegen/通道说明配合使用；质量咨询可参考但不触发生图。不用于必须采用代码/SVG 的原生资产。普通生图不读取私人画像记忆。

## Procedure
1. 先区分生成、编辑、系列任务。保留用户原文，按用途、主体数量动作、构图交付、风格材质、必须保留、禁止项、允许变化整理。新增假设单独标注，只有影响交付或费用的歧义才追问；检查相互冲突要求并定优先级。
2. 按场景选验收项：人物重身份动作解剖；商品重结构零件；海报重层级留白；文字信息图重逐字与数据关系并优先后期排版；空间重透视尺度；透明素材重边缘alpha；系列重跨图一致。不要套固定摄影风、无人物或方图。
3. 先查看参考图，明确每张职责：编辑底稿、身份、产品结构、构图或风格。冲突先筛选，含UI截图先提取纯图或询问。按任务只取必要参考，不自动搜索最近图片当底稿。
4. 调用前读取适用工具规则并核对当前schema；按通道/模型/transport/生成或编辑/参数组合选择已验证能力，区分接口接受与实测有效。历史尺寸、费用、水印和编辑结果仅是带日期样本；未知标未知，不批量试探计费尺寸网格。
5. 明确预算：一张图默认一次生成，不默认双通道、多候选或追加编辑。已有明确授权无需重复问；比较、重生成、跨通道、transport 变化或独立 API 计费须在批准范围内。不要给你所用通道不存在的参数（如某些通道没有 size/quality/mask，或 model 只是路由模型）；「最近图片选择器」与「本地参考路径」两类入参不要同时传。参数对照见附录 A。
6. 发送结构化但简洁的提示词：任务、主体空间关系、构图、分材质视觉要求、优先硬约束、允许变化、少量禁止项、参考职责、编辑不变量。记录原文和发送版本；返回改写仅检查增添遗漏冲突，不索取或保存隐藏推理。
7. 异步返回ID就查询同一任务，等待有界，暂停保留ID；不重复生成。成功立即保存原始字节，不覆盖原件，实际格式与扩展名匹配。临时下载先检查HTTP和解码再正式落盘；签名URL不进长期记录。
8. 验收三层：文件可解码/尺寸格式alpha；需求主体数量文字构图禁止项；场景视觉解剖材质光影层级边缘一致性。硬门槛失败不由审美总分抵消。OCR和模型自评只是辅助，高频/锐度不代表质量；未能目视则标未验收。
9. 按问题选修法：缩放格式调色准确排版优先本地；局部瑕疵定向编辑；整体结构失败调整方案后在预算内重生成。每轮一个主要目标，同时明确保留项与验收标准。无mask工具不保证其他像素不变；严格锁区需已验证蒙版/合成路线。
10. 每轮与最近合格底稿比较目标改善和非目标漂移。保留版本与parent，不将最新结果自动当最佳；失败回到合格底稿。超时断流连接配额存储错误不自动重生，先恢复已有产物；能查任务 ID / artifact 的通道先查，只能靠本地记录的通道查原任务与仍有效链接。恢复失败报告未知状态和可能消耗。
11. 记录最小sidecar：请求通道与参数、提示词来源、参考职责/哈希、任务ID、父版本、状态/耗时、requested/reported/measured、产物路径/哈希、验收未决项、批准预算与已知费用；未知填null，不存凭据、签名URL或无关个人信息。
12. 交付标明最终文件、使用通道、验收范围和不足。若需验证策略收益，在获准预算内按固定跨场景案例做等需求比较；记录首次可用率、硬约束通过率、编辑漂移、合格图调用量和成本。小样本只作探索，不宣称普遍胜出。

## Pitfalls
- 流程是助手规程，不是插件级强制拦截，也不保证随机输出一致。
- 工具schema含参数不等于所有模型支持；不得自动转CLI或其他计费路径。
- 附录 A 是两条具体通道的实测快照：换版本、换账号、换额度都会变，不得把里面的尺寸、水印、价格当成全局固定规则。
- 生成完成但下载失败不等于需要重新生成；取消后也可能消耗额度。
- 不得把历史个案里的风格、尺寸、水印、价格写成全局固定规则。
## Verification
1. 执行前有明确用途、硬约束和调用预算；普通任务没有读取无关记忆。
2. 输出落盘可解码，实际属性独立检查，旧原件未覆盖。
3. 编辑检查目标和非目标区域；不合格与未知如实报告。
4. 没有未经授权的额外生成、重试、换通道或独立API调用。

## 附录 A：两条通道的实测对照（2026-11-11 快照，会过期）

仅作「怎么区分接口接受与实测有效」的例子，不是推荐，也不是规格。

| 能力 | 通道 A（订阅式） | 通道 B（本地网关，多档模型） |
|---|---|---|
| 取对话内已附图片 | 支持，参数指定取最近 N 张 | 不支持，只吃绝对路径 / URL / base64 |
| 图生图 | 支持 | 仅其中部分模型支持；另一些只文生图，传参考图直接报不支持编辑图像 |
| 尺寸控制 | 不支持任意尺寸 | 部分尺寸报不支持；不传 size 时输出不跟随底图 |
| 水印 | 观察到无 | 观察到固定水印，prompt 不可控（以通道条款为准） |
| 文字约束 | 遵守较好 | 会忽略「无可读文字」而写出可辨字 |
| 提示词改写 | 生成前自动重写，需核对增删 | 未见改写 |

注：水印有无、能否关闭、尺寸上限都由「你所用通道当前的条款与实现」决定，上表不构成对任何产品的描述或规避建议。 未见改写 |

教训：接任务前先核「这个通道支不支持图生图、支不支持要的尺寸」，再谈效果。「换个模型就行」是错的，要先问通道能力。
